# Workout Tracker with Analytics Functionality

This is a multi-user workout tracker with analytics functionalities built using Google Sheets and Google Apps Script. The project was designed to simplify workout submissions, automate logging and scoring workflows, and provide users with dashboards and performance visualizations. 

This project was created to serve as a convenient place to host a workout competition with friends. Real-time monitoring of scores and submissions provided a fun and interactive way to exercise together, even with friends in separate time zones. The following project was copied from a currently running competition. The names have been randomized.

All users given the status "Competitor" would officially rank. Any user not interested in competing could set themselves as a "Neutral Observer". Neutral Observers still have stats but don't officially rank. At the end of the competition, the losers must call the winner Sensei, for some amount of time. The losers must also do some number of burpees as punishment which depend on final ranking.

# Workflow Design

One of the main goals of the project was balancing flexibility and usability for different types of users. The system evolved over time through iterative improvements, including:

- Simplified submissions
- Dynamic visualizations
- User-specific stats
- Exercise difficulty multipliers
- Automated logging and calculations
- Dashboard organization improvements

---

# Project Goals

The main focus of the project was creating a workflow that was:
- Easy for users to interact with
- Flexible enough to support different workout styles
- Scalable for multiple users
- Organized for long-term progress tracking and analytics
- Still functional for users who didn't want to formally compete

The system was continuously refined based on balance testing.
